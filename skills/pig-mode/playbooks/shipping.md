# Playbook: Shipping

**Goal:** Deliver verified, reviewable commits and a short PR briefing when authorized.

1. **Close:** Close Sequence once on the final candidate. Run repository formatters before `deslop`, never after verification.
2. **Commits:** Shape small work-unit commits per odd-protocol section 6.
3. **Delivery:** Push or open a PR only when the user authorized it. Write the PR body with `technical-writing`.

**Reply:** commits or PR link, verification output, `Risk:` line.
